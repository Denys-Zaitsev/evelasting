# Contributing to Evelasting

Thank you for your interest in improving Evelasting.

## Before you begin

Evelasting is an artist website and an actively developed creative project. Please open an issue before starting a substantial change so its scope and direction can be discussed first.

Music, artwork, photography, video, branding, and other original media are not contribution assets and may not be reused outside this project.

## Development workflow

1. Fork the repository and create a focused branch from `main`.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local`. Never commit credentials.
4. Make a small, clearly scoped change.
5. Run `npm run lint` and `npm run build`.
6. Open a pull request using the repository template.

## Guidelines

- Keep the English and Ukrainian experiences consistent.
- Preserve accessibility, responsive behavior, and reduced-motion support.
- Avoid adding dependencies unless they provide clear value.
- Do not include generated build output, secrets, or unrelated formatting changes.
- Include screenshots or recordings for visible interface changes.
- Explain performance and accessibility implications when relevant.

Submitting a contribution does not grant permission to reuse Evelasting's music, visual identity, media, or other protected assets.
